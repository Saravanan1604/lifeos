# icons/
This folder must contain:
- icon-192.png  (192×192 pixels)
- icon-512.png  (512×512 pixels)

HOW TO GENERATE:
1. Open `create-icons.html` in your browser (double-click it)
2. Click "Download icon-192.png" — save it here
3. Click "Download icon-512.png" — save it here
4. Delete this README.txt file

These icons are required for the PWA (Android home screen install).
